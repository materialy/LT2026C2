Przestrzeń nazw std

Nazwy z biblioteki standardowej mają wspólne „nazwisko” std, więc pełna nazwa to std::cout. Bez using namespace std; trzeba ją podawać w całości.

Zadanie: linii using nie ma. Uzupełnij pola, żeby program się skompilował.

#include <iostream>
// brak: using namespace std;
int main()
{
cout << "Kot Filemon" << endl;
return 0;
}

Czy to się skompiluje?

Wszędzie poza opisanymi zmianami program jest poprawny. Wybierz „tak” albo „nie” i sprawdź.

Znajdź 3 błędy

Kliknij linie z błędami, potem „Sprawdź”.

Podpowiedź: średnik, typ, wielkość liter.

Do zapamiętania

  • #include <iostream> dołącza bibliotekę z cout; bez średnika.
  • using namespace std; pozwala pisać cout zamiast std::cout.
  • Program zaczyna się od int main(); main zawsze zwraca int.
  • Ciało funkcji jest w klamrach { }; każda { ma swoją }.
  • Każda instrukcja kończy się średnikiem.
  • return 0; kończy program i zgłasza sukces.
  • C++ rozróżnia wielkość liter: cout ≠ Cout.
  • Komentarze: // do końca linii, /* */ na kilka linii.
