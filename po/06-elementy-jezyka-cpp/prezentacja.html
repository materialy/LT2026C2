Wykonaj program krok po kroku

#include <iostream>
using namespace std;
int main()
{
cout << "Sklep Pod Lipa" << endl;
cout << "Bulki: " << 10 << endl;
cout << "Paczki po 4: " << 10 / 4 << endl;
cout << "Zostaje: " << 10 % 4 << endl;
cout << "Cena paczki: " << 2.5 * 4 << " zl" << endl;
return 0;
}

Do zapamiętania

  • #include to dyrektywa preprocesora, która działa jeszcze przed kompilacją.
  • Słowa kluczowe (int, return, using…) są zarezerwowane i pisze się je małymi literami.
  • Identyfikator to nazwa. main, cout i endl są nazwami, a nie słowami kluczowymi.
  • Nazwa składa się z liter a–z, A–Z, cyfr i _, nie zaczyna się od cyfry i nie ma spacji.
  • Literały: 42, 3.5 (z kropką!), 'A', "tekst", true/false.
  • 7 / 2 daje 3, a 7.0 / 2 daje 3.5. % to reszta z dzielenia.
  • Separatory ; { } ( ) kończą i grupują kod.
  • Białe znaki poza napisami nie mają znaczenia, a C++ rozróżnia wielkość liter.
