Zanim zaczniesz

  • Program zaczyna się od #include <iostream> i using namespace std;, a instrukcje piszesz w int main() { … }.
  • cout << wypisuje na ekran to, co stoi za <<, a kilka rzeczy łączysz kolejnymi <<.
  • Tekst do wypisania ujmujesz w cudzysłów, np. "Hej".
  • endl przenosi wypisywanie do nowej linii.
  • Każda instrukcja kończy się średnikiem.

Kod w C++ składa się z kilku rodzajów „cegiełek”: dyrektyw, słów kluczowych, nazw (identyfikatorów), literałów, operatorów i separatorów. Kto je rozpoznaje, łatwiej czyta cudzy kod i szybciej rozumie komunikaty kompilatora.

02Słowa kluczowe i identyfikatory

Słowa kluczowe

Zarezerwowane, zawsze małymi literami: int, double, char, bool, return, if, else, while, true, false… Code::Blocks wyróżnia je kolorem.

Identyfikatory

To nazwy wymyślone przez programistę albo autorów biblioteki. main i cout są identyfikatorami, a nie słowami kluczowymi. cout istnieje dopiero po #include <iostream>.

Pułapka

Gdy obie liczby są całkowite, / obcina część ułamkową: 7 / 2 daje 3. Żeby dostać 3.5, przynajmniej jedna liczba musi mieć kropkę.

#include <iostream>   // dyrektywa: dołącz bibliotekę iostream
using namespace std;  // słowa kluczowe using, namespace; std to identyfikator

int main()            // int: słowo kluczowe, main: identyfikator
{
    cout << "Kot Filemon" << endl;  // napis       → Kot Filemon
    cout << 'A' << endl;            // znak        → A
    cout << 7 + 3 << endl;          // działanie   → 10
    cout << "7 + 3" << endl;        // tylko tekst → 7 + 3
    cout << 7 / 2 << endl;          // całkowite   → 3
    cout << 7.0 / 2 << endl;        // z kropką    → 3.5
    cout << true << endl;           // logiczna    → 1
    return 0;                       // return: słowo kluczowe, 0: literał
}

04Typowe błędy

  • Int main(), Return 0;: słowa kluczowe pisze się małymi literami.
  • cout << 3,5;: przecinek zamiast kropki. Program wypisze 3, a nie 3.5.
  • cout << "Hej;: bez zamykającego cudzysłowu napis ciągnie się do końca linii i kompilator zgłasza błąd.
  • cout << 'Hej';: w apostrofach mieści się jeden znak. Taki zapis wypisze dziwną liczbę, a tekst ujmuje się w cudzysłów.

06Sprawdź się

Odpowiedz w myślach, potem rozwiń.

Ile słów kluczowych jest w programie Hello world?

Cztery: using, namespace, int, return. main, cout, endl i std to identyfikatory.

Dlaczego 2klasa nie może być nazwą?

Identyfikator nie może zaczynać się od cyfry. Poprawnie: klasa2.

Czym różni się 7 od "7"?

7 to liczba, można nią liczyć: 7 + 1 daje 8. "7" to napis, czyli tekst złożony ze znaku 7.

Czy spacje wokół << są obowiązkowe?

Nie. Białe znaki poza napisami są pomijane. Piszemy je tylko po to, żeby kod był czytelny.

trudniejsze Przewidź wynik: cout << "2 + 2 = " << 2 + 2;

2 + 2 = 4. Napis wypisuje się dosłownie, a 2 + 2 bez cudzysłowu jest działaniem.

trudniejsze Porównaj: cout << 1 / 2; i cout << 1.0 / 2;

Pierwsze wypisze 0, bo dzielą się dwie liczby całkowite i część ułamkowa znika. Drugie wypisze 0.5.

trudniejsze Znajdź błąd: cout << "Wynik: << 5;

Brakuje cudzysłowu po Wynik: . Kompilator uznaje resztę linii za napis i zgłasza brak zakończenia. Poprawnie: cout << "Wynik: " << 5;

trudniejsze cout działa w każdym programie. Dlaczego mimo to nie jest słowem kluczowym?

To nazwa (identyfikator) z biblioteki iostream. Bez #include <iostream> kompilator zgłosi, że cout nie został zadeklarowany. Słowa kluczowe działają zawsze, bez dołączania czegokolwiek.
