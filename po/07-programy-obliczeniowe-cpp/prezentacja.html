Wczytaj dane, policz według wzoru, wypisz wynik w zdaniu. Tak działa każdy prosty program obliczeniowy, od sumy dwóch liczb po pole kwadratu.

→ pole = 10000

Sterowanie: strzałki ← →, spacja lub przyciski na dole.

Co zrobimy

Kliknij temat, aby do niego przejść.

Dane → obliczenia → wynik

Program z lekcji: suma dwóch liczb. Wpisz, co poda użytkownik, i wykonaj program linijka po linijce.

int a, b, suma;
cout << "Podaj 1 liczbe: ";
cin >> a;
cout << "Podaj 2 liczbe: ";
cin >> b;
suma = a + b;
cout << "Suma liczb " << a << " i " << b << " to " << suma << endl;

Wzór z matematyki → wyrażenie w C++

Wybierz wzór i zapisz go w C++. Sprawdzę go na trzech zestawach danych.

Wzór:

= ;

w C++ nie ma ani ², ani ·, ani :

Wpisz wyrażenie i kliknij „Sprawdź”.

Kolejność działań: co pojawi się na ekranie?

Wpisz, co wypisze każda linijka. Najpierw * /, potem + -, a nawiasy zmieniają kolejność.

← wpisz odpowiedzi i kliknij „Sprawdź”

    Do zapamiętania

    • Program obliczeniowy ma trzy części: dane (komunikat + cin), obliczenia, wynik (cout).
    • Licz dopiero po wczytaniu. Wcześniej zmienne mają przypadkowe wartości.
    • Mnożenie to zawsze *: 2 * a, 2 * (a + b).
    • Kwadrat to a * a, bo ^ nie jest w C++ potęgą.
    • Najpierw * / %, potem + -. Nawiasy zmieniają kolejność.
    • Tekst w cudzysłowie wypisuje się dosłownie, a wyrażenie bez cudzysłowu jest obliczane.
    • Spacje w zdaniu z wynikiem wpisujesz wewnątrz cudzysłowu: " i ".
    • Sprawdź program na danych z polecenia, a potem na własnych.
