Zanim zaczniesz

  • Zmienną deklarujesz przed użyciem: typ i nazwa, np. int bok; kilka zmiennych jednego typu rozdzielasz przecinkami: int a, b;
  • int przechowuje liczby całkowite, a double liczby z kropką, np. 2.5.
  • cin >> a; wczytuje do zmiennej a liczbę wpisaną przez użytkownika.
  • Przed cin wypisz komunikat, np. cout << "Podaj bok: "; żeby użytkownik wiedział, co ma wpisać.
  • Przypisanie wynik = a + b; najpierw liczy prawą stronę, a potem zapisuje wynik w zmiennej po lewej.

Program obliczeniowy wczytuje dane, liczy według wzoru i wypisuje wynik w czytelnym zdaniu. Tutaj zobaczysz, jak z polecenia zadania zrobić działający program.

01Trzy kroki: dane → obliczenia → wynik

KrokCo robi programW C++
1. Dane (wejście)wypisuje komunikat i wczytuje liczbycout << "Podaj bok: "; cin >> bok;
2. Obliczenialiczy wzór i zapisuje wynik w zmiennejpole = bok * bok;
3. Wynik (wyjście)wypisuje zdanie z tekstem i wartościamicout << "Pole: " << pole;

Kolejność jest stała: najpierw wczytaj, potem licz, na końcu wypisz. Przykład: suma dwóch liczb.

#include <iostream>

using namespace std;

int main()
{
    int a, b, suma;            // dwie liczby i miejsce na wynik

    // 1. Dane: najpierw komunikat, potem wczytanie
    cout << "Podaj 1 liczbe: ";
    cin >> a;
    cout << "Podaj 2 liczbe: ";
    cin >> b;

    // 2. Obliczenia: dopiero teraz a i b mają wartości
    suma = a + b;

    // 3. Wynik: tekst w cudzysłowie, zmienne bez cudzysłowu
    cout << "Suma liczb " << a << " i " << b << " to " << suma << endl;

    return 0;
}

Przebieg w konsoli (liczby 2 i 3 wpisuje użytkownik):

Podaj 1 liczbe: 2
Podaj 2 liczbe: 3
Suma liczb 2 i 3 to 5

Polecenie = przebieg

Zadanie często pokazuje przykładowy przebieg programu. Teksty z polecenia wypisujesz przez cout, a liczby wpisuje użytkownik.

Testuj

Uruchom program z danymi z polecenia i porównaj wynik. Potem spróbuj 0 i liczby ujemnej.

W napisach dla konsoli piszemy bez polskich liter („liczbe”), bo konsola Windows często pokazuje je jako krzaki.

02Wzór z matematyki → wyrażenie w C++

MatematykaC++Uwaga

a²a * a^ w C++ nie oznacza potęgi

Kolejność działań jest jak w matematyce: najpierw * / %, potem + -, a działania o tym samym priorytecie od lewej do prawej. Nawiasy zmieniają kolejność: 2 + 3 * 4 to 14, a (2 + 3) * 4 to 20.

Wynik w zmiennej

pole = bok * bok; Wygodne, gdy wynik jest potrzebny kilka razy albo wzór jest długi.

Wynik od razu w cout

cout << bok * bok; Wystarczy, gdy wynik wypisujesz tylko raz.

Tekst w cudzysłowie wypisuje się dosłownie, a wyrażenie bez cudzysłowu jest najpierw obliczane. Spacje liczą się tylko wewnątrz cudzysłowu.

04Typowe błędy

Pułapka

Obliczenie przed cin: suma = a + b; nad cin >> a; liczy na przypadkowych wartościach. Późniejsze wczytanie nie zmienia już suma.

  • bok^2 to nie kwadrat. Napisz bok * bok.
  • 2a albo 2(a + b) to błąd kompilacji. Brakuje *.
  • cout << "suma"; wypisze słowo suma, a nie wartość.
  • "Suma liczb" << a bez spacji przed zamknięciem cudzysłowu skleja tekst z liczbą.
  • a + b / 2 to nie średnia. Najpierw wykona się dzielenie, więc napisz (a + b) / 2.

06Sprawdź się

Odpowiedz w myślach, potem rozwiń.

Z jakich trzech części składa się prosty program obliczeniowy?

Dane (komunikat i cin), obliczenia (wzór) i wynik (cout).

Program na pole kwadratu dla boku 2 wypisał 4. Czy to znaczy, że na pewno działa dobrze?

Nie. Błędne bok * 2 też daje 4 dla boku 2. Sprawdź inne dane, np. bok 3: ma wyjść 9, a nie 6.

Jak zapisać w C++ obwód prostokąta 2(a + b)?

2 * (a + b). Znak mnożenia trzeba napisać.

Co wypisze cout << 10 - 2 * 3;?

4, bo najpierw mnożenie: 2 * 3 = 6, potem 10 - 6.

Kiedy warto zapisać wynik w osobnej zmiennej, a nie liczyć go w cout?

Gdy wynik jest potrzebny kilka razy albo wzór jest długi. Kod jest wtedy czytelniejszy.

trudniejsze Znajdź błąd: obwod = 2 * a + b; dla a = 3 i b = 4 daje 10, a obwód prostokąta to 14.

Mnożenie wykonuje się przed dodawaniem, więc program liczy 2 * 3 + 4. Potrzebny jest nawias: 2 * (a + b).

trudniejsze Co wypisze cout << "Wynik:" << 3 << 4;?

Wynik:34. Dwie liczby wypisane jedna po drugiej sklejają się, bo między nimi nie ma spacji.

trudniejsze Dla int a = 2, b = 3; wyrażenie (a + b) / 2 daje 2, a nie 2.5. Dlaczego i jak to naprawić?

Dzielenie dwóch int obcina część ułamkową. Zadeklaruj double a, b; albo dziel przez 2.0.

07Spróbuj sam

  1. Otwórz bledy.cpp. To program sumy dwóch liczb z trzema błędami. Popraw go tak, żeby dla 2 i 3 wypisał dokładnie Suma liczb 2 i 3 to 5.
    Podpowiedź

    Sprawdź kolejność linii, spacje w cudzysłowach i to, czy wypisujesz wartość zmiennej, czy jej nazwę.

    Rozwiązanie
    cin >> b;
suma = a + b;      // obliczenie po wczytaniu
cout << "Suma liczb " << a << " i " << b << " to " << suma << endl;
  2. Uzupełnij kwadrat.cpp: po wpisaniu boku 100 ma się pojawić Pole kwadratu o boku 100 wynosi: 10000. Potem dopisz obwód kwadratu.
    Rozwiązanie
    int bok, pole, obwod;
cout << "Podaj bok kwadratu: ";
cin >> bok;
pole = bok * bok;
obwod = 4 * bok;
cout << "Pole kwadratu o boku " << bok << " wynosi: " << pole << endl;
cout << "Obwod kwadratu wynosi: " << obwod << endl;
  3. Uzupełnij srednia.cpp: program wczytuje dwie oceny i wypisuje ich średnią. Dla 4 i 5 ma wyjść 4.5.
    Podpowiedź

    Oceny zadeklaruj jako double i pamiętaj o nawiasach przy dodawaniu.

    Rozwiązanie
    double o1, o2, srednia;
cout << "Podaj 1 ocene: ";
cin >> o1;
cout << "Podaj 2 ocene: ";
cin >> o2;
srednia = (o1 + o2) / 2;
cout << "Srednia ocen to " << srednia << endl;
