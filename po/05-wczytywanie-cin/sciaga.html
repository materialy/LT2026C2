Zanim zaczniesz

  • cout << wypisuje tekst i wartości w konsoli, a kolejne elementy łączysz następnymi <<.
  • endl przenosi wypisywanie do nowej linii.
  • Zmienną deklarujesz przed użyciem: typ i nazwa, np. int wiek; albo string imie;
  • int przechowuje liczby całkowite, double liczby z kropką, string tekst.
  • Nazwa zmiennej bez cudzysłowu daje jej wartość, tekst w cudzysłowie wypisuje się dosłownie.

cin wczytuje dane wpisane na klawiaturze do zmiennej. Program zatrzymuje się na cin i czeka, aż użytkownik coś wpisze i naciśnie Enter.

01cin >> zmienna

cout <<

Dane płyną z programu na ekran. Za << stoi napis, liczba albo zmienna.

cin >>

Dane płyną z klawiatury do zmiennej. Za >> stoi zawsze zmienna, nigdy napis.

ZapisCo robi
cin >> imie;wczytuje jedno słowo do zmiennej imie (typ string)
cin >> wiek;wczytuje liczbę całkowitą do wiek (typ int)
cin >> a >> b;wczytuje dwie wartości; użytkownik oddziela je spacją albo Enterem

Strzałki pokazują kierunek danych: w cin >> x wartość wpada do x. Zmienna musi być zadeklarowana wcześniej.

02Przykład: przywitanie

#include <iostream>
#include <string>
using namespace std;

int main()
{
    string imie;               // tu trafi wpisane słowo
    int wiek;                   // tu trafi wpisana liczba

    cout << "Podaj imie: ";    // komunikat: co wpisać
    cin >> imie;               // program czeka na Enter
    cout << "Ile masz lat? ";
    cin >> wiek;

    cout << "Witaj " << imie << "!" << endl;
    cout << "Za rok: " << wiek + 1 << " lat" << endl;
    return 0;
}

Konsola po wpisaniu Filemon i 15:

Podaj imie: Filemon
Ile masz lat? 15
Witaj Filemon!
Za rok: 16 lat

Spacja na końcu "Podaj imie: " oddziela komunikat od tego, co wpisuje użytkownik. Enter, który naciska użytkownik, przenosi kursor do nowej linii.

03Co trafi do zmiennej

cin >> pomija spacje na początku i kończy wczytywanie na pierwszej spacji albo na znaku, który nie pasuje do typu. Reszta czeka w buforze na następne cin.

int x4.94.9

int xabc0, błąd wczytaniaabc

04Całe zdanie: getline

getline(cin, zdanie);

Wczytuje całą linię razem ze spacjami, aż do Enter. Zmienna musi być typu string. Dla Kot Filemon dostaniesz cały tekst, a nie samo Kot.

05Typowe błędy

Pułapka

getline zaraz po cin >> liczba; wczyta pusty tekst, bo w buforze został Enter. Przed getline dopisz cin.ignore();.

  • cin << imie;: strzałki w złą stronę. Przy cin zawsze >>.
  • cin >> "imie";: do napisu nie da się nic wczytać. Za >> stoi zmienna.
  • cin >> wiek; bez int wiek; wyżej: kompilator nie zna nazwy wiek.
  • Brak komunikatu przed cin: kursor miga, a użytkownik nie wie, co wpisać.
  • cout << "Witaj" << imie;: wyjdzie WitajFilemon. Dopisz spację w napisie: "Witaj ".

06Słowniczek

cin
standardowe wejście programu, czyli zwykle klawiatura (z biblioteki iostream)
>>
operator wczytywania: przenosi wartość z cin do zmiennej
komunikat
tekst wypisany przed cin, który mówi użytkownikowi, co ma wpisać
Enter
klawisz, który kończy wpisywanie; dopiero po nim program wczytuje dane
bufor wejścia
miejsce, gdzie czeka wpisany tekst, którego żadne cin jeszcze nie zabrało
białe znaki
spacja, tabulator i Enter; cin >> traktuje je jak przerwę między wartościami
błąd wczytania
sytuacja, gdy wpisany tekst nie pasuje do typu (litery do int); kolejne cin przestają działać
getline(cin, s)
wczytuje do string s całą linię razem ze spacjami
cin.ignore()
usuwa z bufora jeden znak, zwykle Enter po poprzednim wczytaniu

07Sprawdź się

Odpowiedz w myślach, potem rozwiń.

Co robi program, gdy dochodzi do cin >> x;?

Zatrzymuje się i czeka, aż użytkownik wpisze wartość i naciśnie Enter. Dopiero wtedy wykonuje kolejne instrukcje.

Jak jedną instrukcją wczytać wzrost i wagę do zmiennych wzrost i waga?

cin >> wzrost >> waga; Użytkownik wpisuje obie liczby oddzielone spacją albo Enterem.

Co trafi do string s, gdy wpiszesz Jan Testowy?

Tylko Jan. Spacja kończy wczytywanie, a Testowy czeka w buforze.

Dlaczego napis komunikatu kończy się zwykle spacją, np. "Podaj wiek: "?

Żeby to, co wpisze użytkownik, nie sklejało się z dwukropkiem: Podaj wiek: 15 zamiast Podaj wiek:15.

trudniejsze Przewidź wynik: int a, b; cin >> a >> b; cout << a + b;, gdy wpiszesz 7 8.

15. Do a trafia 7, do b trafia 8, a a + b to wyrażenie.

trudniejsze string x, y; cin >> x; cin >> y; Wpisujesz Kot Filemon i Enter. Ile razy program na Ciebie poczeka?

Raz. Pierwsze cin bierze Kot, a drugie od razu zabiera Filemon z bufora.

trudniejsze Porównaj cin >> zdanie; i getline(cin, zdanie); dla tekstu Kot lubi mleko.

Pierwsze daje Kot, drugie cały tekst Kot lubi mleko.

08Spróbuj sam

  1. Otwórz plik startowy main.cpp. Wczytaj imię kota i jego wiek, a potem wypisz zdanie Filemon ma 3 lat. Przed każdym cin daj komunikat.
    Rozwiązanie
    cout << "Imie kota: ";
cin >> imie;
cout << "Wiek kota: ";
cin >> wiek;
cout << imie << " ma " << wiek << " lat" << endl;
  2. Uruchom program i na pytanie o imię wpisz Kot Filemon. Co stało się z pytaniem o wiek? Popraw wczytywanie imienia tak, żeby działało dla dwóch słów.
    Podpowiedź

    Program nie czekał na wiek: cin >> imie wziął Kot, a Filemon nie pasuje do int, więc wczytanie wieku się nie udało.

    Rozwiązanie
    getline(cin, imie);   // zamiast cin >> imie;
  3. Dopisz kalkulator: wczytaj dwie liczby całkowite jedną instrukcją i wypisz ich sumę oraz iloczyn.
    Rozwiązanie
    int a, b;
cout << "Podaj dwie liczby: ";
cin >> a >> b;
cout << "Suma: " << a + b << endl;
cout << "Iloczyn: " << a * b << endl;
