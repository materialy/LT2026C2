Program musi coś zapamiętać: wynik, imię, cenę. Do tego służą zmienne: pudełka w pamięci z nazwą, typem i wartością.

Do zapamiętania

  • Zmienna ma typ, nazwę i wartość: int c = 10;
  • int to liczby całkowite, double liczby z kropką, string tekst w cudzysłowie.
  • Kilka zmiennych tego samego typu: int c = 10, b = 5, a = 3;
  • Zmienną trzeba zadeklarować, zanim się jej użyje.
  • Zmienna bez wartości (int suma;) ma przypadkową wartość.
  • = znaczy „wstaw do”: prawa strona liczy się pierwsza, stara wartość znika.
  • cout << a + b; liczy, cout << "a + b"; wypisuje dosłownie.
  • Do typu string dopisuj #include <string>.
