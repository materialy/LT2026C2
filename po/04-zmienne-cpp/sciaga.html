Zanim zaczniesz

  • Identyfikator (nazwa) zaczyna się od litery lub _, nie ma spacji ani polskich znaków i nie może być słowem kluczowym.
  • Literał to wartość wpisana wprost w kodzie, np. 10, 2.5 albo "Kot Filemon".
  • Operatory + - * / liczą wartości, a 7 / 2 na liczbach całkowitych daje 3.
  • cout << wypisuje wartość na ekran, kolejne elementy łączysz następnymi <<.
  • Wielkość liter ma znaczenie: Wynik i wynik to dwie różne nazwy.

Zmienna to miejsce w pamięci komputera, które ma nazwę i przechowuje jedną wartość, np. liczbę albo tekst. Dzięki zmiennym program może zapamiętać dane, liczyć na nich i zmieniać je w trakcie działania.

01Zmienna: nazwa, typ, wartość

Typ

Mówi, co wolno w niej trzymać: int przechowuje liczby całkowite, string tekst. Typu nie da się później zmienić.

Nazwa i wartość

Nazwa to identyfikator, np. suma. Wartość to to, co aktualnie leży w zmiennej, i może się zmieniać.

TypCo przechowujePrzykład
intliczby całkowite (także ujemne)int wiek = 16;
doubleliczby z częścią ułamkową, zapisywane z kropkądouble cena = 4.50;
stringtekst w cudzysłowiestring imie = "Filemon";

Do typu string dopisz #include <string>. W Code::Blocks program zadziała też bez tego, ale nie w każdym kompilatorze.

02Deklaracja, inicjalizacja, przypisanie

CzynnośćZapisCo się dzieje
deklaracjaint suma;tworzy zmienną; jej wartość jest przypadkowa
inicjalizacjaint c = 10;tworzy zmienną i od razu nadaje jej wartość
kilka narazint c = 10, b = 5, a = 3;trzy zmienne tego samego typu, oddzielone przecinkami
przypisaniea = 7;nowa wartość zastępuje starą, stara znika

Znak = nie oznacza tu równości jak w matematyce. Czytaj go jako „wstaw do”: najpierw liczy się prawa strona, wynik trafia do zmiennej po lewej.

03Przykład: zmienne w wyrażeniach

#include <iostream>
#include <string>
using namespace std;

int main()
{
    // trzy zmienne int w jednej linii
    int c = 10, b = 5, a = 3;
    double cena = 4.50;          // liczba z kropką
    string imie = "Filemon";     // tekst w cudzysłowie

    int suma;                    // deklaracja bez wartości
    suma = a + b + c;            // przypisanie wyniku: 18

    cout << "Suma: " << suma << endl;  // Suma: 18
    cout << "a + b" << endl;           // a + b (to napis)
    cout << a + b << endl;             // 8 (to wyrażenie)

    a = 7;                       // stara wartość 3 znika
    a = a + 1;                   // weź a (7), dodaj 1, wstaw do a
    cout << imie << " ma " << a << " lat" << endl;  // Filemon ma 8 lat
    cout << "Cena: " << cena << endl;  // Cena: 4.5
    return 0;
}
  • Nazwa bez cudzysłowu to zmienna: cout << a; wypisze jej wartość.
  • Tekst w cudzysłowie to napis: cout << "a"; wypisze literę a.
  • cout << 4 + 2; wypisze 6, a cout << "4 + 2"; wypisze 4 + 2.

04Typowe błędy

Pułapka

Zmienna zadeklarowana bez wartości (int suma;) zawiera przypadkową liczbę. Zanim ją wypiszesz albo dodasz do niej coś, nadaj jej wartość.

  • wynik = 5; bez wcześniejszego int wynik;: kompilator zgłosi, że nie zna nazwy wynik.
  • int wiek = "16";: w cudzysłowie jest tekst, a do int pasuje tylko liczba.
  • string imie = Filemon;: bez cudzysłowu kompilator szuka zmiennej o nazwie Filemon.
  • 10 = c;: po lewej stronie = zawsze stoi zmienna, do której wstawiasz wartość.
  • double cena = 4,50;: przecinek nie oddziela części ułamkowej. Pisz 4.50.

06Sprawdź się

Odpowiedz w myślach, potem rozwiń.

Czym różni się deklaracja od inicjalizacji?

Deklaracja tylko tworzy zmienną (int x;). Inicjalizacja tworzy ją i od razu nadaje wartość (int x = 5;).

Jaki typ wybierzesz dla liczby uczniów w klasie, a jaki dla średniej ocen?

Liczba uczniów to int (zawsze całkowita), średnia to double (np. 4.25).

Ile zmiennych tworzy linia int x = 1, y, z = 3;?

Trzy: x i z mają wartości, a y ma wartość przypadkową.

Co oznacza zapis punkty = punkty + 5;?

Weź obecną wartość punkty, dodaj 5 i wynik wstaw z powrotem do punkty. Zmienna rośnie o 5.

trudniejsze Przewidź wynik: int a = 2; int b = a; a = 9; cout << b;

2. Do b skopiowano wartość 2. Późniejsza zmiana a nie zmienia b.

trudniejsze Znajdź błąd: int c = 10, b = 5, a = 3; cout << A + b;

Nie ma zmiennej A, jest a. Wielkość liter ma znaczenie, więc kompilator zgłosi błąd.

trudniejsze Porównaj: co wypiszą cout << "c" << c; i cout << c << c;, gdy c = 10?

Pierwsza linia: c10 (napis i wartość). Druga: 1010 (dwa razy wartość, bez odstępu).

07Spróbuj sam

  1. Otwórz plik startowy main.cpp (paragon ze „Sklepu Pod Lipą”). Zadeklaruj trzy zmienne: nazwę produktu, liczbę sztuk i cenę jednej sztuki.
    Rozwiązanie
    string produkt = "zeszyt w kratke";
int sztuk = 3;
double cena = 2.50;
  2. Policz wartość zakupów w zmiennej razem i wypisz linię w stylu 3 x zeszyt w kratke = 7.5 zl.
    Podpowiedź

    Wynik mnożenia ceny przez sztuki ma część ułamkową, więc razem musi być typu double.

    Rozwiązanie
    double razem = sztuk * cena;
cout << sztuk << " x " << produkt << " = " << razem << " zl" << endl;
  3. Klient dokłada 2 sztuki. Zwiększ sztuk przypisaniem, policz razem od nowa i wypisz paragon jeszcze raz.
    Rozwiązanie
    sztuk = sztuk + 2;   // teraz 5
razem = sztuk * cena;   // 12.5, bez słowa double: zmienna już istnieje
cout << sztuk << " x " << produkt << " = " << razem << " zl" << endl;
  4. Zamień wartości zmiennych x = 4 i y = 9 tak, żeby było x = 9 i y = 4. Nie wpisuj liczb wprost.
    Podpowiedź

    Po x = y; stara wartość x znika. Najpierw schowaj ją w trzeciej zmiennej.

    Rozwiązanie
    int schowek = x;   // schowek = 4
x = y;              // x = 9
y = schowek;        // y = 4
